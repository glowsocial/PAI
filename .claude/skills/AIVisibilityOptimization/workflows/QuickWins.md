# Quick Wins Workflow

**Trigger:** "quick wins for [domain]", "fast improvements for [business]", "what's the fastest way to improve visibility"

## Purpose

Generate a prioritized list of 5 high-impact, low-effort actions that can improve AI visibility within 1-2 weeks.

## Process

### Step 1: Quick Assessment

Do a rapid check of:
1. **Schema** - Does the site have FAQPage schema?
2. **Directories** - Is the business on G2/Clutch/Capterra?
3. **Content volume** - How many pages are indexed? (`site:domain.com`)
4. **Reviews** - Any visible reviews/testimonials?
5. **robots.txt** - Are AI crawlers blocked?

### Step 2: Match Gaps to Quick Wins

| Gap Found | Quick Win | Time | Impact |
|-----------|-----------|------|--------|
| No directory listings | Submit to Clutch + GoodFirms | 2-3 hrs | +7-10 pts |
| No FAQ schema | Create FAQ page with schema | 4-6 hrs | +8-12 pts |
| No reviews visible | Request 5 testimonials | 1-2 hrs | +4-6 pts |
| robots.txt blocks AI | Add AI crawler Allow rules | 30 min | +3 pts |
| Only 1-2 pages indexed | Create 3 service pages | 4-6 hrs | +5-8 pts |
| No case studies | Write 1 case study with metrics | 2-3 hrs | +3-5 pts |
| No Google Business Profile | Create and verify GBP | 1 hr | +3 pts |
| Missing industry directory | Apply to partner program | 1 hr | +5 pts |

### Step 3: Prioritize by ROI

**Tier 1: Do This Week**
- Highest impact per hour invested
- Usually: directories, robots.txt, GBP

**Tier 2: Do Next Week**
- Medium effort, good payoff
- Usually: FAQ schema, testimonials

**Tier 3: Start Planning**
- Higher effort but necessary
- Usually: content pages, case studies

## Common Quick Win Templates

### Directory Submission
```markdown
## Submit to B2B Directories ⏱️ 2-3 hours

**Impact:** +7-10 points
**Why:** Clutch and GoodFirms are heavily cited by AI for service recommendations.

**Steps:**
1. Go to clutch.co/register and create company profile
2. Go to goodfirms.co/add-your-company and submit
3. Fill ALL fields completely (AI favors complete profiles)
4. Add 3+ services with descriptions
5. Upload logo and team photos
```

### FAQ Schema
```markdown
## Create FAQ Page with Schema ⏱️ 4-6 hours

**Impact:** +8-12 points
**Why:** FAQ schema increases AI sessions by 527%. This is the #1 content format AI systems extract.

**Steps:**
1. Identify 10 most common questions about your service
2. Write 40-60 word answers for each (extractable length)
3. Create /faq page with questions and answers
4. Add FAQPage schema markup (template provided)
5. Submit to Google Search Console for indexing
```

### robots.txt Fix
```markdown
## Update robots.txt for AI Crawlers ⏱️ 30 minutes

**Impact:** +3 points
**Why:** Many AI crawlers respect robots.txt. Explicit Allow rules signal you want to be indexed.

**Steps:**
1. Access your robots.txt file (usually at domain.com/robots.txt)
2. Add these lines:

User-agent: GPTBot
Allow: /

User-agent: ClaudeBot
Allow: /

User-agent: PerplexityBot
Allow: /

User-agent: Google-Extended
Allow: /

3. Save and verify the file is accessible
```
