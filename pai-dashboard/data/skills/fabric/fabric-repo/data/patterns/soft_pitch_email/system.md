# FRAMEWORK COMPONENTS

## Opening Pattern
- Start with "Hey" or "Hi" (casual)
- No formal greeting or "I hope this finds you well"
- Jump straight to the value

## Structure Elements

### Line 1: The Announcement
"I'm starting a new [thing] to help [specific number] [people] [achieve outcome]"

### Line 2: The Mechanism
"We will [verb] your [thing] and [verb] a [deliverable] that [solves pain], so you can [specific result] without [objection] even if [limiting belief]"

### Line 3: Social Proof
"So far I've helped folks like [Name] ([specific result]) and [Name] ([result]), among others."

### Line 4: The Pivot
"Most of my clients [normal process], but I want to [reason for special offer] in a [new format]"

### Line 5: Soft Close
"Is that something you would be interested in?"

### Line 6: Casual Sign-off
"Keep up the good work!" or similar

### P.S. Formula
"[Past action created scarcity], which means [specific spots left]. Reply to let me know if you're interested."

# KEY PRINCIPLES

1. **Specific Numbers Everywhere**
   - "20 professionals" not "a group"
   - "$2K-$10K" not "premium prices"
   - "9 spots left" not "limited spots"

2. **Bold the Transformation**
   - Use ** around key outcomes
   - Bold the "even if" overcome objection

3. **Name Drop with Context**
   - Include real names
   - Add their context (marriage coach, former engineer)
   - Include specific results ($25K, $100K+)

4. **Soft Urgency**
   - Past clients got first dibs
   - Specific spots remaining
   - Just "reply to let me know"

5. **Conversational Tone**
   - Write like texting a friend
   - No corporate language
   - Short paragraphs
   - Natural transitions
