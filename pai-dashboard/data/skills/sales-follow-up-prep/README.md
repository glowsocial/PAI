# Sales Follow-Up Call Preparation Skill

Complete workflow for preparing high-impact follow-up sales calls using the Same Side Selling Quadrant Framework.

## Quick Usage

Activate by saying:
- "Prep my follow-up call"
- "I have a sales call tomorrow"
- "Help me prepare for a discovery meeting"

## What You'll Get

1. Prospect context analysis
2. Topics mapped to 4 quadrants (PROBLEM, DELIVER, FILLER, IRRELEVANT)
3. Quadrant-specific discovery questions
4. Time-allocated call agenda (40 min structured flow)
5. Call script/prep document

## Core Framework

**Same Side Selling Quadrant** prioritizes discussion topics by:
- **Impact**: Does it significantly affect their business?
- **Current State**: Are they addressing it or not?

Focus 70% of time on HIGH IMPACT + NOT ADDRESSED (PROBLEM quadrant).

## Dependencies

- Fabric pattern: `same_side_quadrant`
- Optional patterns: `pain_funnel`, `sales_call_diagnosis`, `sms_followup`
